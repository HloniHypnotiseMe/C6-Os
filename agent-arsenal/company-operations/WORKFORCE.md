# C6 Workforce Registry

The workforce registry maps business roles to the smallest sufficient execution layer.

## Resolution order

1. Resolve the business job.
2. Resolve an existing capability.
3. Check existing C6 skill/agent/workflow/team.
4. Benchmark registered upstream providers.
5. Adapt only the missing layer.
6. Declare permissions and human approvals.
7. Define evidence.
8. Verify and register.

## Worker contract

Every worker requires:

- mission/job;
- trigger;
- inputs;
- outputs;
- capability;
- execution layer;
- permissions;
- forbidden actions;
- human approval boundary;
- evidence contract;
- success criteria;
- provenance and lifecycle.

## No agent inflation

A role does not automatically become an agent.

Use:

- skill for a reusable procedure;
- agent for a specialist execution identity;
- workflow for ordered stateful work;
- team for coordinated specialists;
- provider for the implementation source;
- human where authority or configured risk requires it.

## Workforce admission

A worker is not active merely because its file exists. Admission requires capability resolution, provenance, permissions, evidence contract, verification plan and successful verification.

The workforce registry is an operating control plane, not a list of AI personalities.
