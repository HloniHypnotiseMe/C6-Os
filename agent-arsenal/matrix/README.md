# C6 Problem-Solution Matrix

This matrix is the commercial control plane for C6.

Flow:
**Pain → Evidence → Capability → Provider → Adapter → Package → Success intervention → Outcome**

Use it to drive:
- Business Audit diagnosis
- package recommendations
- AI Staff selection
- Revenue Hunter matching
- C6 /packages and /ai-tools truth
- Success dashboard actions

Start with research-supported candidates, then promote rows only after business-specific evidence is collected and the execution chain is verified.

The initial inventory intentionally contains gaps. That is a feature: C6 must not sell machinery that is only registered in the Arsenal.
